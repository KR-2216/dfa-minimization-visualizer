DFA Minimization

Reducing finite automata to their simplest equivalent form

§1 What is a Deterministic Finite Automaton?

A Deterministic Finite Automaton (DFA) is a 5-tuple M = (Q, Σ, δ, q₀, F) where:

  • Q — a finite, non-empty set of states
  • Σ — a finite set called the alphabet
  • δ : Q × Σ → Q — the transition function
  • q₀ ∈ Q — the start state
  • F ⊆ Q — the set of accept states

Given an input string w = a₁a₂…aₙ, the DFA processes each symbol sequentially, transitioning between states. The string is accepted if the machine ends in an accept state; otherwise it is rejected.

§2 Why Minimize?

Multiple DFAs can recognize exactly the same language. Among all such equivalent DFAs, there exists a unique (up to state renaming) minimum-state DFA. Minimization matters because:

⚡

Performance

Fewer states mean faster transitions in lexers, pattern matchers, and network filters.

◈

Uniqueness

The minimal DFA is a canonical representation, enabling equality testing of languages.

∿

Insight

Merging redundant states clarifies the automaton's logical structure.

§3 Distinguishable States

Two states p, q ∈ Q are distinguishable if there exists a string w ∈ Σ* such that exactly one of δ*(p, w) and δ*(q, w) is in F. Conversely, they are indistinguishable (or equivalent) if no such string exists.

Base Case

Any accept state is distinguishable from any non-accept state (the empty string ε witnesses this).

Inductive Step

States p and q are distinguishable if there exists a ∈ Σ such that δ(p,a) and δ(q,a) are distinguishable.

§4 Myhill–Nerode Theorem

The Myhill–Nerode theorem gives a precise characterisation of regular languages and their minimal automata.

Definition. For a language L ⊆ Σ*, define the equivalence relation ≡_L on strings: x ≡_L y iff for every z ∈ Σ*, xz ∈ L ⟺ yz ∈ L.

Theorem (Myhill–Nerode)

A language L is regular if and only if ≡_L has finitely many equivalence classes. Moreover, the number of equivalence classes equals the number of states in the minimum DFA for L.

Each equivalence class corresponds to exactly one state of the minimal DFA. This is the theoretical foundation underlying all minimization algorithms.

§5 Table-Filling Algorithm

Also called the mark-distinguishable-pairs algorithm, this is the procedure implemented in this visualizer.

Algorithm: Table-Filling (Mark) Method
  1. Construct a triangular table of all state pairs {p, q} with p ≠ q.
  2. Mark every pair {p, q} where one is an accept state and the other is not.
  3. Repeat until no new marks:
    1. For each unmarked pair {p, q} and each symbol a ∈ Σ:
    2. If {δ(p,a), δ(q,a)} is already marked, mark {p, q}.
  4. Merge all unmarked (indistinguishable) pairs into single states.
  5. Construct the minimized DFA from the merged state classes.

The time complexity of this algorithm is O(|Q|² · |Σ|), making it practical even for large automata.

§6 Hopcroft's Algorithm

Hopcroft's algorithm (1971) achieves a superior time complexity of O(|Q| · |Σ| · log|Q|) using a partition-refinement strategy.

Algorithm: Hopcroft's Partition Refinement
  1. Initialise partition P = {F, Q \ F} (accept vs. non-accept states).
  2. Initialise worklist W = {F, Q \ F}.
  3. While W ≠ ∅:
    1. Remove a set A from W.
    2. For each a ∈ Σ, let X = δ⁻¹(A, a) (states that transition into A on a).
    3. For each set Y ∈ P that intersects both X and Y \ X:
      • Replace Y with Y ∩ X and Y \ X in P.
      • Update worklist accordingly.
  4. Each block of the final partition P becomes one state of the minimized DFA.

§7 Worked Example

Consider the DFA with states Q = {A, B, C, D, E}, alphabet Σ = {0, 1}, start state A, and accept states C, D:

ABCStart
BBD—
CBCAccept

EBC—

Step 1 — Initial partition: P₀ = {{C, D}, {A, B, E}}

Step 2 — Refine on symbol 1: All of A, B, E go to C or D (accept) on 1 — but check symbol 0: A→B, B→B, E→B. They behave identically on 0 as well. So {A, B, E} doesn't refine further.

Step 3 — Check {C, D}: C on 0→B, D on 0→B; C on 1→C, D on 1→C. They are indistinguishable. Merge C and D.

Result: Minimal DFA has 3 states: [A,B,E] (non-accept) and [C,D] (accept). Note: A and E are also merged — the minimal DFA has states {[A,E], [B], [C,D]} after checking on symbol 1 (A→C/D, B→C/D, E→C/D — same; but on 0: A→B, B→B, E→B — same. On 1: A→C, B→D, both in [C,D] — same).

The minimal DFA collapses from 5 states to 3 states.
